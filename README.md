# Report Generator

This library provides extensible classes to query and extract data from the database, then save the results as spreadsheets.

In the future I plan to introduce an external domain-specific language to make the report generation description (programing)-language-agnostic

## Features

- Query the database for specific data
- Generate reports in Excel format
- Easy to use and configure

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/araujoarthur/reportgen.git
   ```
2. Navigate to the project directory:
   ```sh
   cd reportgen
   ```
3. Install the required dependencies:
   ```sh
   pip install -r requirements.txt
   ```
